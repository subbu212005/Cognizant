# Agile User Stories

In Agile, requirements are not captured in massive specification documents. Instead, we write **User Stories**—short, simple descriptions of a feature told from the perspective of the person who desires the new capability (the user).

## Learning Goals

In this section, you will learn:
* Why user stories focus on the user's problem rather than the technical solution.
* How to slice large requirements (Epics) into small, estimable stories.
* How to write clear, testable Acceptance Criteria that eliminate ambiguity.
