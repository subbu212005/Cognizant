## Learning Objectives

By the end of this module, you will be able to:
1. **Explain** the underlying philosophy of Agile and contrast it with traditional plan-driven (Waterfall) methodologies.
2. **Advocate** for the four core values and twelve principles of the Agile Manifesto.
3. **Define and distinguish** Scrum roles, ceremonies, artifacts, and commitments.
4. **Facilitate** relative estimation using Planning Poker and calculate sprint velocity.
5. **Draft** high-quality user stories containing clear Gherkin-style Acceptance Criteria.
6. **Establish** an empirical workflow that values transparency, inspection, and adaptation.
