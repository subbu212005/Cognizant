# Exercise 5: Task Management System

Implements a Singly Linked List for task management.

## Linked Lists
- Singly Linked List: Nodes point to the next node.
- Doubly Linked List: Nodes point to both previous and next nodes.

## Operations
- Add
- Search
- Traverse
- Delete

## Time Complexity

| Operation | Complexity |
|---|---:|
| Add (end) | O(n) |
| Search | O(n) |
| Traverse | O(n) |
| Delete | O(n) |

## Advantages over Arrays
- Dynamic size
- Efficient insert/delete without shifting elements
- No contiguous memory requirement
