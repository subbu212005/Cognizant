# Exercise 1: Inventory Management System

## Aim
Develop an Inventory Management System using C# and Dictionary for efficient storage and retrieval.

## Data Structure
Dictionary<int, Product>

## Operations
- Add Product
- Update Product
- Delete Product
- Display Products

## Time Complexity

| Operation | Complexity |
|-----------|------------|
| Add | O(1) |
| Update | O(1) |
| Delete | O(1) |
| Search | O(1) |
