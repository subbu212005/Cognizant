# Exercise 3: Sorting Customer Orders

Implements Bubble Sort and Quick Sort to sort customer orders by total price.

## Time Complexity

| Algorithm | Best | Average | Worst |
|---|---:|---:|---:|
| Bubble Sort | O(n) | O(n²) | O(n²) |
| Quick Sort | O(n log n) | O(n log n) | O(n²) |

Quick Sort is generally preferred because of its average O(n log n) performance.
