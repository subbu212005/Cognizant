# Section 2: Prompt Engineering

This section covers the core techniques of Prompt Engineering. You will learn how to design, write, and refine prompts to get high-quality, predictable, and contextually accurate responses from Large Language Models.

## Learning Objectives

- Understand the fundamental structure of a well-formed prompt.
- Apply prompting techniques including Zero-shot, Few-shot, and Chain-of-Thought (CoT).
- Design and implement system instructions/system prompts to guide behavior.
- Structure model outputs into machine-readable formats like JSON, XML, or Markdown tables.
- Recognize and implement strategies to prevent prompt injection and mitigate model hallucination.

## Key Topics Covered

1. **Anatomy of a Prompt**: Input text, instruction, context, examples, and output formatting.
2. **Core Prompting Paradigms**:
   - Zero-shot Prompting: Asking the model directly.
   - Few-shot Prompting: Providing demonstrations of inputs and desired outputs.
   - Chain-of-Thought (CoT): Encouraging step-by-step reasoning.
3. **System Prompts vs. User Prompts**: How system instructions set behavioral boundaries and personas.
4. **Structuring Outputs**: Techniques for schema compliance, JSON validation, and markdown tables.
5. **Mitigation Tactics**: Context-limiting, source grounding, and prompt defense strategies.
