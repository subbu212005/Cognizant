# Section 1: Introduction to Generative AI

This section provides a foundation for understanding Generative Artificial Intelligence (GenAI). You will learn the difference between traditional machine learning models and generative models, explore Large Language Models (LLMs), and examine the core concepts behind the Transformer architecture.

## Learning Objectives

- Define Generative AI and distinguish it from traditional, analytical AI.
- Explain the key milestones in the evolution of generative models.
- Describe the high-level architecture of Large Language Models (LLMs).
- Understand the role of tokenization, embeddings, and attention mechanisms.
- Identify the limitations and common capabilities of current foundation models.

## Key Topics covered

1. **What is Generative AI?**: Definition, generative vs. discriminative/predictive models.
2. **Foundations of LLMs**: Natural Language Processing (NLP) history, introduction to Transformers.
3. **Core Mechanisms**: Tokenization, embeddings, vector space, and the Self-Attention mechanism.
4. **Model Architecture Types**: Decoder-only (e.g., GPT), Encoder-only (e.g., BERT), and Encoder-Decoder (e.g., T5) models.
5. **Capabilities and Boundaries**: Text generation, translation, code writing, alongside model constraints like context limits and knowledge cutoff dates.
