# Section 3: Introduction to GitHub Copilot

This section introduces GitHub Copilot, an AI-powered developer tool that acts as an AI pair programmer. You will learn the history of Copilot, how it works under the hood using Large Language Models, and the ways it integrates into the development workflow.

## Learning Objectives

- Explain what GitHub Copilot is and define its role as an AI pair programmer.
- Describe how Copilot operates using generative models like OpenAI Codex and newer GPT/Gemini models.
- Differentiate between the primary interfaces: Copilot Completions (inline) and Copilot Chat.
- Understand the scope of context that Copilot uses from your active files to make recommendations.
- Discuss the efficiency gains and productivity metrics associated with AI-assisted coding.

## Key Topics Covered

1. **What is GitHub Copilot?**: Overview of the tool, collaborative programming paradigm, and developer statistics.
2. **How Copilot Works**: Model foundations (Codex, GPT, Gemini), context gathering from open tabs, cursor position, and files in the workspace.
3. **Core Interfaces**:
   - Ghost Text (Inline Completions)
   - Panel Completions (Multiple suggestions)
   - Copilot Chat (Conversational interface)
4. **Context and Privacy**: How code snippets are sent, processed, and returned as recommendations.
