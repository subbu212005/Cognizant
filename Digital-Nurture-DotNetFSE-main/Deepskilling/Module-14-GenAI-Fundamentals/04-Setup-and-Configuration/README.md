# Section 4: Setup and Configuration

This section provides the necessary setup steps to install, configure, and authenticate GitHub Copilot in your environment. You will configure the extension across popular IDEs and manage settings for telemetry and code filtering.

## Learning Objectives

- Install the GitHub Copilot and GitHub Copilot Chat extensions in VS Code, Visual Studio, or JetBrains IDEs.
- Authenticate the extension with a GitHub account hosting an active Copilot subscription (Individual, Business, or Enterprise).
- Configure Copilot settings, including enabling/disabling inline suggestions and keyboard shortcut customizations.
- Manage privacy settings, including telemetry preferences and the public code matching filter.

## Key Topics Covered

1. **Prerequisites**: Account check, subscription licensing (Copilot Individual vs. Copilot Business/Enterprise).
2. **IDE Installation Guides**:
   - Visual Studio Code setup.
   - Visual Studio setup.
   - JetBrains (IntelliJ, PyCharm, WebStorm) setup.
3. **Authentication Workflow**: Logging into GitHub, device codes, and authorization approvals.
4. **Configuration settings**: Turning completions on/off, customizing keyboard shortcuts, and setting up proxies.
