# Useful Links and Resources

This document compiles official documentation, tutorials, and guides for further learning.

---

## 1. Official GitHub Copilot Documentation

- **GitHub Copilot Documentation**: Official user manuals and configuration guides.
  `https://docs.github.com/en/copilot`
- **GitHub Copilot in VS Code**: Guide specifically for Visual Studio Code features.
  `https://code.visualstudio.com/docs/editor/github-copilot`
- **GitHub Copilot in JetBrains**: Installation and usage details for PyCharm, IntelliJ, and other JetBrains IDEs.
  `https://docs.github.com/en/copilot/using-github-copilot/getting-started-with-github-copilot/getting-started-with-github-copilot-in-a-jetbrains-ide`
- **GitHub Copilot Trust Center**: Details regarding security, code privacy, and data usage.
  `https://resources.github.com/copilot-trust-center/`

---

## 2. Prompt Engineering Guides

- **OpenAI Prompt Engineering Guide**: Official tactics and strategies to improve model outputs.
  `https://platform.openai.com/docs/guides/prompt-engineering`
- **Prompting Guide (DAIR.AI)**: Comprehensive, community-driven resource for all aspects of prompting.
  `https://www.promptingguide.ai/`
- **Google GenAI Prompting Guide**: Guidance for writing prompts for Gemini models.
  `https://cloud.google.com/vertex-ai/docs/generative-ai/learn/introduction-prompt-design`

## 3. Training and Certification

- **GitHub Foundations Certification**: Learning path covering Git, GitHub features, and Copilot.
  `https://learn.microsoft.com/en-us/training/paths/github-foundations/`
- **GitHub Copilot Learning Path**: Microsoft Learn interactive modules for developing with Copilot.
  `https://learn.microsoft.com/en-us/training/paths/copilot/`
