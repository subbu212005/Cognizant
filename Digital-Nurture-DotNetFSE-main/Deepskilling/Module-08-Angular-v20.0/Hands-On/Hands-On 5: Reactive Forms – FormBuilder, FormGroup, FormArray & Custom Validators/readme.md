# Hands-On 5: Reactive Forms – FormBuilder, FormGroup, FormArray & Custom Validators

## Overview

This hands-on enhances the Student Course Portal by replacing the template-driven enrollment form with a Reactive Form. The project demonstrates the use of FormBuilder, FormGroup, FormControl, FormArray, built-in validators, custom synchronous validators, and asynchronous validators.

---

## Learning Objectives

- Understand Reactive Forms
- Create forms using FormBuilder
- Use FormGroup and FormControl
- Implement FormArray
- Apply built-in validators
- Create custom synchronous validators
- Create asynchronous validators
- Display validation messages
- Handle dynamic form controls

## Angular CLI Commands

Create Reactive Form Component

```bash
ng generate component pages/reactive-enrollment-form
```

Create Validator

```bash
mkdir src/app/validators
```

Run Application

```bash
ng serve
```

Build Project

```bash
ng build
```
