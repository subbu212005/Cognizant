# Module 08 – Angular

## Overview
This module provides a comprehensive introduction to Angular, one of the most popular front-end frameworks for building modern, scalable, and responsive web applications. It covers Angular fundamentals, component-based architecture, forms, routing, services, HTTP communication, state management using NgRx, and unit testing with Jasmine and Karma.

Through a series of hands-on exercises, learners gain practical experience in developing real-world Angular applications using best practices.

---

## Learning Objectives

After completing this module, you will be able to:

- Understand Angular architecture and project structure.
- Build reusable components.
- Implement data binding and component communication.
- Use directives and custom pipes.
- Create Template-Driven and Reactive Forms.
- Implement custom validation.
- Work with Angular Services and Dependency Injection.
- Configure Routing and Lazy Loading.
- Protect routes using Route Guards.
- Consume REST APIs using HttpClient.
- Handle asynchronous data with RxJS Observables.
- Create HTTP Interceptors.
- Implement state management using NgRx.
- Write unit tests using Jasmine, Karma, and TestBed.
