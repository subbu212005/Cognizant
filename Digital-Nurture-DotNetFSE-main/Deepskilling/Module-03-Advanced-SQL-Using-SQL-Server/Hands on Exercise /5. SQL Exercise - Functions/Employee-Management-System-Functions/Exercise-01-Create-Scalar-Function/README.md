# Exercise 01 – Create a Scalar Function

## Objective

Create a scalar function named **fn_CalculateAnnualSalary** to calculate the annual salary of an employee.

## Problem Statement

The function should accept the employee's monthly salary as input and return the annual salary.

**Formula:**

Annual Salary = Salary × 12

## Files Included

- Solution.sql
- Output.md
- ex1.png

## Expected Output

The function returns the annual salary for every employee.

## Learning Outcome

- Understand scalar functions.
- Create reusable SQL functions.
- Return a single calculated value.
