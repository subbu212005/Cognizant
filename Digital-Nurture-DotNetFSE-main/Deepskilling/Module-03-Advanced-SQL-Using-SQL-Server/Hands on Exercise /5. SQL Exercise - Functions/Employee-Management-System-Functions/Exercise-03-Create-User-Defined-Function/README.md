# Exercise 03 – Create a User-Defined Function

## Objective

Create a user-defined function named **fn_CalculateBonus**.

## Problem Statement

The function should calculate 10% of the employee's salary as a bonus.

**Formula:**

Bonus = Salary × 0.10

## Files Included

- Solution.sql
- Output.md
- ex3.png

## Expected Output

Returns the calculated bonus for each employee.

## Learning Outcome

- Create scalar user-defined functions.
- Perform mathematical calculations.
