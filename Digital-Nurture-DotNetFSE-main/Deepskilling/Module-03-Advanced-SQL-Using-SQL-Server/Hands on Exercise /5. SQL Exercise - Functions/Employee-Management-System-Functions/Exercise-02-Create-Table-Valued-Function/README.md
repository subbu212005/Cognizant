# Exercise 02 – Create a Table-Valued Function

## Objective

Create a table-valued function named **fn_GetEmployeesByDepartment**.

## Problem Statement

The function should accept a DepartmentID and return all employees belonging to that department.

## Files Included

- Solution.sql
- Output.md
- ex2.png

## Expected Output

Displays employee details for the selected department.

## Learning Outcome
