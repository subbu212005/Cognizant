# Exercise 05: Delete Trigger

### Objective
Learn how to delete (drop) triggers in SQL Server for both table-level triggers and server-level triggers.

### Steps
1. Write the SQL script to drop the `trg_AfterInsertEmployee` trigger.
2. Write the SQL script to drop the server-level `trg_AuditLogon` trigger.
3. Verify that the triggers no longer exist in the system catalog.
