# Exercise 03 – Custom Error with RAISERROR

## Objective

Validate employee salary using RAISERROR.

## Problem Statement

Before inserting an employee, verify that the salary is greater than zero. If the salary is invalid, display the custom message:

**Salary must be greater than zero.**

## Files Included

- Solution.sql
- Output.md
- ex3.png

## Expected Output

A custom error is displayed when the salary is invalid.

## Learning Outcome

- Create custom validation rules.
- Use RAISERROR.
- Enforce business logic.
