# Exercise 02 – Using THROW to Re-raise Errors

## Objective

Log an error and then re-raise it using the THROW statement.

## Problem Statement

Modify the **AddEmployee** procedure so that after logging the error in **AuditLog**, it uses **THROW** to pass the exception back to the calling application.

## Files Included

- Solution.sql
- Output.md
- ex2.png

## Expected Output

The error is logged and then re-raised to the client application.

## Learning Outcome

- Use THROW.
- Propagate exceptions.
- Combine logging with error reporting.
