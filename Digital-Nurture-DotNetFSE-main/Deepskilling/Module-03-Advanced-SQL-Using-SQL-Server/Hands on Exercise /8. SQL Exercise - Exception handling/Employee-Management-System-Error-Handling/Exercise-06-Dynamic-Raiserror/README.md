# Exercise 06 – Dynamic RAISERROR with Severity and State

## Objective

Raise different messages based on salary conditions using RAISERROR.

## Problem Statement

Modify **AddEmployee** so that:

- Salary below **1000** generates a warning (Severity 10).
- Negative salary generates an error (Severity 16).

Use RAISERROR with different severity levels and states.

## Files Included

- Solution.sql
- Output.md
- ex6.png

## Expected Output

Appropriate warnings or errors are displayed depending on the salary value.

## Learning Outcome

- Understand RAISERROR severity levels.
- Use different state values.
- Implement advanced business validations.
