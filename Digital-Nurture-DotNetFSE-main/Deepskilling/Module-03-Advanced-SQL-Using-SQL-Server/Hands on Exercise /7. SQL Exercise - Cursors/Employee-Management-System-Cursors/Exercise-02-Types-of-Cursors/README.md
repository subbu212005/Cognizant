# Exercise 02 – Types of Cursors

## Objective

Understand the different types of cursors available in SQL Server.

## Problem Statement

Create and compare the following cursor types:

- Static Cursor
- Dynamic Cursor
- Forward-Only Cursor
- Keyset-Driven Cursor

Observe how each cursor behaves when data changes during cursor execution.

## Files Included

- Solution.sql
- Output.md
- ex2.png

## Expected Output

Demonstrates the behavior and differences between the four cursor types.

## Learning Outcome

- Understand Static cursors.
- Understand Dynamic cursors.
- Understand Forward-Only cursors.
- Understand Keyset-Driven cursors.
- Compare cursor performance and behavior.
