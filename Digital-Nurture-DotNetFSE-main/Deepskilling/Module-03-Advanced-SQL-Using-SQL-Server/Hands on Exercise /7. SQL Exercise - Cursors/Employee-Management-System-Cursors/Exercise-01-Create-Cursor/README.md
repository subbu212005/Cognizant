# Exercise 01 – Create a Cursor

## Objective

Create a SQL Server cursor to iterate through all employee records and display their details.

## Problem Statement

Declare a cursor that selects all records from the **Employees** table. Open the cursor, fetch each record one by one, display the employee details, and then close and deallocate the cursor.

## Files Included

- Solution.sql
- Output.md
- ex1.png

## Expected Output

Displays each employee's details sequentially using the cursor.

## Learning Outcome

- Declare cursors.
- Open and fetch cursor records.
- Close and deallocate cursors.
- Process rows individually.
