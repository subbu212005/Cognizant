# Exercise 06 - Output Parameters

## Aim

To use output parameters in a stored procedure.

---

## Objective

Create a stored procedure that calculates the total salary of employees in a department using an OUTPUT parameter.

---

## Prerequisites

- Microsoft SQL Server
- SQL Server Management Studio (SSMS)

---

## Files

- Solution.sql
- Ex6.png

---

## Procedure

1. Create the stored procedure.
2. Declare an OUTPUT parameter.
3. Calculate the total salary.
4. Execute the stored procedure.
5. Display the returned value.

---

## Expected Output

The total salary of employees in the selected department is displayed.

---

## Result

The stored procedure successfully returned the total salary using an OUTPUT parameter.

---

## Learning Outcome

- Understand OUTPUT parameters.
- Return values from stored procedures.
