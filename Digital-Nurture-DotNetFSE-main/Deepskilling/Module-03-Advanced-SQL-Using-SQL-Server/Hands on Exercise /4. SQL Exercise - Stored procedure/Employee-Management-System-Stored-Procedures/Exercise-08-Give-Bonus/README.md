# Exercise 08 - Give Bonus

## Aim

To create a stored procedure with conditional logic.

---

## Objective

Create a stored procedure named **sp_GiveBonus** that adds a bonus to employees belonging to a specific department.

---

## Prerequisites

- Microsoft SQL Server
- SQL Server Management Studio (SSMS)

---

## Files

- Solution.sql
- Ex8.png

---

## Procedure

1. Create the stored procedure.
2. Pass DepartmentID and BonusAmount.
3. Execute the stored procedure.
4. Verify the updated employee salaries.

---

## Expected Output

Employees in the selected department receive the specified bonus.

---

## Result

The stored procedure successfully updated employee salaries with the bonus.

---

## Learning Outcome

- Learn conditional logic in stored procedures.
- Perform UPDATE operations using parameters.
