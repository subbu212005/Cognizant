# Exercise 01 - Create Stored Procedure

## Aim

To create a stored procedure that inserts a new employee into the Employees table.

---

## Objective

Create a stored procedure named **sp_InsertEmployee** that accepts employee details as parameters and inserts a new record into the Employees table.

---

## Prerequisites

- Microsoft SQL Server
- SQL Server Management Studio (SSMS)
- Employee Management System Database

---

## Files

- Solution.sql
- Ex1.png

---

## Procedure

1. Open SQL Server Management Studio.
2. Connect to the Employee Management database.
3. Open **Solution.sql**.
4. Execute the script.
5. Execute the stored procedure using sample values.
6. Verify the inserted employee record.

---

## Expected Output

A new employee record is successfully inserted into the Employees table.

---

## Result

The stored procedure was created and executed successfully.

---

## Learning Outcome

- Understand Stored Procedures.
- Learn Parameterized SQL.
- Perform INSERT operations using Stored Procedures.
