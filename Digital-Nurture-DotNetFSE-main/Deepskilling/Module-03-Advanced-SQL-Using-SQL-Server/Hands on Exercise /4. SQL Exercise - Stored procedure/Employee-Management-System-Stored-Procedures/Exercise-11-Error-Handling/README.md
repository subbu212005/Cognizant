# Exercise 11 - Error Handling in Stored Procedure

## Aim

To create a stored procedure that handles runtime errors using TRY...CATCH.

---

## Objective

Create a stored procedure that updates employee salary and displays a custom error message whenever an error occurs.

---

## Prerequisites

- Microsoft SQL Server
- SQL Server Management Studio (SSMS)
- Employee Management System Database

---

## Files

- Solution.sql
- Ex11.png

---

## Procedure

1. Open SQL Server Management Studio.
2. Connect to the Employee Management database.
3. Create the stored procedure using **TRY...CATCH**.
4. Execute the stored procedure.
5. Verify successful execution.
6. Trigger an error and observe the custom error message.

---

## Expected Output

The salary is updated successfully. If an error occurs, a meaningful custom error message is displayed.

---

## Result

The stored procedure successfully handled runtime errors using the **TRY...CATCH** block.

---

## Learning Outcome

- Learn exception handling in SQL Server.
- Use TRY...CATCH for robust stored procedures.
- Improve reliability and maintainability of database applications.
