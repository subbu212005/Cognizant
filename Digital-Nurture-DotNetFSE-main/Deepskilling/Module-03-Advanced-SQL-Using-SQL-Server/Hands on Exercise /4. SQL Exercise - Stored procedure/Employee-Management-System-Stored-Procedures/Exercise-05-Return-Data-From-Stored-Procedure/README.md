# Exercise 05 - Return Data from a Stored Procedure

## Aim

To create a stored procedure that returns the total number of employees in a department.

---

## Objective

Create a stored procedure that accepts **DepartmentID** as input and returns the total number of employees in that department.

---

## Prerequisites

- Microsoft SQL Server
- SQL Server Management Studio (SSMS)
- Employee Management System Database

---

## Files

- Solution.sql
- Ex5.png

---

## Procedure

1. Open SQL Server Management Studio.
2. Connect to the Employee Management database.
3. Create the stored procedure.
4. Pass the DepartmentID as a parameter.
5. Execute the stored procedure.
6. Verify the returned employee count.

---

## Expected Output

Displays the total number of employees in the selected department.

---

## Result

The stored procedure returned the correct employee count.

---

## Learning Outcome

- Learn aggregate functions inside stored procedures.
- Return summarized information from SQL Server.
