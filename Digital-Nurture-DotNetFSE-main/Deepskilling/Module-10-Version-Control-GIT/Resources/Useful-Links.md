# Useful Git Links & Resources

A curated list of tutorials, interactive sandboxes, references, books, and GUI clients to help you master Git.

---

## 📖 Official Documentation & Books

* **[Official Git Website](https://git-scm.com/)**: The primary home of Git, containing software downloads and core documentation.
* **[Pro Git Book](https://git-scm.com/book/en/v2)**: The definitive, comprehensive guide to Git by Scott Chacon and Ben Straub. Available online for free.
* **[Git Reference Manual](https://git-scm.com/docs)**: Detailed reference pages for every single Git command.

---

## 🎮 Interactive Learning & Games

* **[Learn Git Branching](https://learngitbranching.js.org/)**: An interactive tutorial with sandbox visualization. Highly recommended for understanding merging, rebasing, and branch navigation.
* **[Oh My Git!](https://ohmygit.org/)**: An open-source, interactive game that visualizes Git repositories in real-time, helping players build intuition for commands.
* **[GitHub Skills](https://skills.github.com/)**: Interactive, hands-on tutorials hosted directly on GitHub to learn GitHub-specific flows, actions, and features.
* **[Git Immersion](https://gitimmersion.com/)**: A guided tour through the fundamentals of Git, designed to teach you the details of Git's commands by doing them.

---

## 🔍 Visualizers & Playgrounds

* **[Visualizing Git](https://git-school.github.io/visualizing-git/)**: A web-based sandbox tool where you can type commands and instantly see how the local repository graph updates.
* **[Git Graph Visualizer](https://onlywei.github.io/explain-git-with-d3/)**: Visualizes common Git operations (commit, branch, checkout, merge, rebase) using D3 animations.

---

## 🛠️ Recommended GUI Clients & Extensions

While mastering the command line is important, using a graphical tool can make managing complex merges and inspecting diffs much easier.

* **[Lazygit](https://github.com/jesseduffield/lazygit)**: A simple, highly responsive terminal-based UI for Git commands. Excellent for keyboard-centric developers.
* **[VS Code GitLens](https://gitlens.amadeus.dev/)**: An indispensable extension for VS Code that provides inline authorship (blame) annotations, repository navigation, and history comparison.
* **[GitKraken](https://www.gitkraken.com/)**: A powerful cross-platform GUI client featuring visually rich graph displays and built-in conflict resolution tools.
* **[Sourcetree](https://www.sourcetreeapp.com/)**: A free Git desktop client for Mac and Windows by Atlassian, supporting both Git and Mercurial.
* **[GitHub Desktop](https://desktop.github.com/)**: A clean, streamlined client built by GitHub, optimized for simpler, everyday workflows.

## 📄 Cheat Sheets (PDFs)

* **[GitHub Git Cheat Sheet PDF](https://education.github.com/git-cheat-sheet-education.pdf)**: An official, high-quality, printable cheat sheet from GitHub.
* **[GitLab Git Cheat Sheet PDF](https://about.gitlab.com/images/press/git-cheat-sheet.pdf)**: A quick-reference cheat sheet from GitLab highlighting common workflows.
