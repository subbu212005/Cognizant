# Module 10 – Version Control - GIT

## Overview

This module provides a comprehensive introduction to **Git**, the most widely used Distributed Version Control System (DVCS) in modern software development. It covers the fundamental concepts of version control, Git installation and configuration, basic Git commands, branching and merging strategies, remote repositories, and collaborative workflows using GitHub.

Through theory, practical exercises, and hands-on labs, learners gain experience in managing source code, tracking changes, collaborating with team members, and maintaining project history. The module also introduces Git best practices and workflow strategies commonly followed in enterprise software development.

---

## Learning Objectives

After completing this module, learners will be able to:

- Explain the concepts of Version Control Systems.
- Understand the architecture of Git as a Distributed Version Control System (DVCS).
- Install and configure Git on different operating systems.
- Use essential Git commands for managing repositories.
- Create, switch, merge, and delete branches.
- Resolve merge conflicts.
- Work with remote repositories using GitHub.
- Perform push, pull, fetch, and clone operations.
- Understand collaborative development using Forks and Pull Requests.
- Apply Git Flow and Feature Branch workflows in real-world projects.
