# Exercise 4: Remote Branches

## Goal
Understand how to view, track, and delete branches on a remote Git server.

## Scenario
You are working on a team project. A colleague has created a branch named `feature-login` and pushed it to the remote repository. You need to inspect the remote branches, switch to that branch locally to work on it, and clean up an old deprecated branch (`old-feature`) on the remote server.

## Steps

1.  **List all branches**: Learn to view local branches, remote-tracking branches, and all branches.
2.  **Track a remote branch**: Switch to the remote branch `feature-login` by checking it out. Git will automatically create a local branch and link it to the remote branch.
3.  **Delete a remote branch**: Clean up the remote server by deleting a remote branch named `old-feature`.
