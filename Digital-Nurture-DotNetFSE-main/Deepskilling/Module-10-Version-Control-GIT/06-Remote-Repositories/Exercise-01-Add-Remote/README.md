# Exercise 1: Add Remote

## Goal
Connect a newly created local Git repository to a remote server by configuring a remote repository URL.

## Scenario
You have created a small project locally, initialized a Git repository, and made your first commit. Now, you need to prepare it for collaboration by linking it to a remote repository URL (simulating a GitHub repository).

## Steps

1.  **Initialize local repository**: Initialize Git in a practice directory.
2.  **Create content and commit**: Add a basic file and record the first commit.
3.  **Inspect current remotes**: Verify that no remote connections exist yet.
4.  **Add a remote URL**: Link your local repository to a remote repository URL (use a dummy GitHub URL for practice: `https://github.com/your-username/remote-exercise.git`).
5.  **Verify the configuration**: List the details of your newly configured remote to ensure it is mapped correctly.
