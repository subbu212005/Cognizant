# 06. Git Remote Repositories

Welcome to the Git Remote Repositories guide and exercise set! In this section of the Git tutorial series, you will learn how to collaborate with others by connecting your local repository to a remote hosting service (such as GitHub, GitLab, or Bitbucket).

## Objectives

By the end of this module, you will be able to:
1. Explain what a remote repository is and why we use it.
2. Connect a local Git repository to a remote server.
3. Push branches and commits to a remote repository.
4. Fetch and pull changes made by others from a remote repository.
5. Manage, track, and interact with remote branches.

---

## Directory Structure

This module is organized into educational notes and four hands-on exercises:

*   **[Notes.md](Notes.md)**: A conceptual deep-dive into remote repositories, remotes, URLs, origin, and standard collaboration workflows.
*   **[Exercise-01-Add-Remote/](Exercise-01-Add-Remote/README.md)**: Adding a remote server to a local repository.
*   **[Exercise-02-Git-Push/](Exercise-02-Git-Push/README.md)**: Pushing branches and commits to a remote server.
*   **[Exercise-03-Git-Pull/](Exercise-03-Git-Pull/README.md)**: Retrieving and merging changes from a remote server.
*   **[Exercise-04-Remote-Branches/](Exercise-04-Remote-Branches/README.md)**: Understanding and working with remote-tracking branches.

---

## How to Complete the Exercises

1.  **Read the Concept Notes**: Start with [Notes.md](Notes.md) to understand the core theories.
2.  **Go Through Each Exercise**: Navigate to the exercise directories in order (01 to 04).
3.  **Follow the Instructions**: Read the `README.md` inside each exercise folder.
4.  **Execute the Commands**: Run the commands listed in `Commands.md` inside a local terminal or practice repository to see the behavior firsthand.
5.  **Compare Output**: Check your terminal results with the sample terminal image provided in `Output.png`.
