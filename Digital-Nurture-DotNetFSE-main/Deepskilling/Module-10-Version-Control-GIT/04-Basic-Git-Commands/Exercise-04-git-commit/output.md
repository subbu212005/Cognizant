# Exercise 04 – git commit

## Command Executed

```bash
git add .
git commit -m "Initial commit"
```

## Output

```text
C:\Users\subbu\GitDemo>git add .

C:\Users\subbu\GitDemo>git commit -m "Initial commit"
[master (root-commit) 6731c68] Initial commit
 1 file changed, 1 insertion(+)
 create mode 100644 file.txt
```

## Observation

The `git commit` command successfully created the first commit in the repository with the message **"Initial commit"**. Git assigned the commit ID `6731c68`, and the staged file `file.txt` is now permanently stored in the repository history.

## Result

The initial commit was successfully created in the Git repository.
