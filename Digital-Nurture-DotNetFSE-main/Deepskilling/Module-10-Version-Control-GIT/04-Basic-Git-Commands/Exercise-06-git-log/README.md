# Exercise 06 – git log

## Objective

Learn how to view the commit history of a Git repository.

## Steps

1. Open the terminal.
2. Navigate to your Git repository.
3. Run the `git log` command.
4. View the commit history.

## Commands

```bash
git log
```

You can also use:

```bash
git log --oneline
git log --graph
```

## Expected Result

Git displays the commit history, including the commit ID, author, date, and commit message.
