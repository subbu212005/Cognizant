# Exercise 05 – git status

## Objective

Learn how to check the current status of a Git repository.

## Steps

1. Open the terminal.
2. Navigate to your Git repository.
3. Run the `git status` command.
4. Observe the repository status.

## Command

```bash
git status
```

## Expected Result

Git displays the current status of the repository, including the current branch and whether there are any staged, unstaged, or untracked files.
