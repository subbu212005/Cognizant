# Exercise 01 – git init

## Command Executed

```bash
mkdir GitDemo
cd GitDemo
git init
```

## Output

```text
Initialized empty Git repository in C:/Users/subbu/GitDemo/.git/
```

## Observation

The `git init` command successfully initialized an empty Git repository. A hidden `.git` folder was created to store the repository's configuration, commit history, branches, and other Git metadata.
