# Module 04 – Basic Git Commands

## Overview

This module introduces the most commonly used Git commands required for everyday version control. These commands help developers initialize repositories, clone existing repositories, stage files, commit changes, check repository status, and view commit history.

By completing these exercises, learners will gain practical experience with the Git workflow used in software development projects.

---

## Learning Objectives

After completing this module, you will be able to:

- Initialize a Git repository.
- Clone an existing repository.
- Stage files using Git.
- Commit changes with meaningful messages.
- Check repository status.
- View commit history.
- Understand the standard Git workflow.

---

## Prerequisites

- Git installed on your system.
- Git configured with username and email.
- Basic command-line knowledge.
- A terminal such as Git Bash, PowerShell, or Command Prompt.
