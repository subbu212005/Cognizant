# Exercise 03 – git add

## Objective

Learn how to stage files using the `git add` command before committing changes.

## Steps

1. Create a new file.
2. Check the repository status.
3. Stage the file using `git add`.
4. Verify that the file is staged.

## Commands

```bash
echo Hello > file.txt
git add .
git status
```

## Expected Result

The file `file.txt` is added to the staging area and is ready to be committed.
