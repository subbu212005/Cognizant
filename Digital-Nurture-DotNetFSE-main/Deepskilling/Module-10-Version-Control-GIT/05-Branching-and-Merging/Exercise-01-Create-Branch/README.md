# Exercise 01: Creating a Branch

In this exercise, you will learn how to create a new branch in Git. 

## Objectives
- Create a new branch named `feature-login`.
- Verify the list of branches in your repository.
- Understand how branches point to commits.

## Background Context
By default, Git repositories start with a default branch, typically named `main` or `master`. Creating a branch allows you to isolate a line of development without affecting the default branch. Since a branch in Git is just a lightweight pointer, creating a branch happens instantaneously.

## Instructions
1. Open your terminal in your repository directory.
2. Ensure you have at least one commit on your default branch. (Git does not allow creating other branches if there are no commits yet!).
3. Run the command to create the new branch.
4. List the branches to verify it was created successfully.

Check the **[Commands.md](./Commands.md)** file for the specific commands to run.
