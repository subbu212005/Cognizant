# Docker & Kubernetes Useful Links

A curated list of official documentation portals, learning platforms, interactive sandboxes, and developer tools.

---

## 📘 Official Documentation & Reference

* **[Docker Official Documentation](https://docs.docker.com/)**
  * The ultimate guide for Docker install guides, Dockerfile references, Compose specs, and CLI commands.
* **[Kubernetes Documentation Portal](https://kubernetes.io/docs/)**
  * Complete user manuals for K8s API objects, installation, configuration, and cluster administration.
* **[Docker Hub Registry](https://hub.docker.com/)**
  * The official library and repository host for pre-built official images (e.g. Node, Python, Alpine, Postgres).
* **[Open Container Initiative (OCI)](https://opencontainers.org/)**
  * Specifications page for container runtime and image standards.

---

## 🎮 Interactive Learning & Sandboxes

* **[Play with Docker (PWD)](https://labs.play-with-docker.com/)**
  * A free, web-based playground that lets you run Docker commands, build images, and cluster hosts directly in your browser (requires a Docker ID login).
* **[Killercoda K8s Playgrounds](https://killercoda.com/)**
  * Interactive, browser-based environments that provide pre-configured Kubernetes clusters for hands-on learning scenario practice.
* **[Katacoda (O'Reilly)](https://www.oreilly.com/online-learning/interactive-learning.html)**
  * interactive learning modules for learning DevOps tooling and container configurations.

---

## 🛠️ Essential Developer Tools

* **[Docker Desktop Dashboard](https://www.docker.com/products/docker-desktop/)**
  * The graphical user interface for Docker Desktop, useful for visual log monitoring, volume analysis, and container inspection.
* **[Portainer](https://www.portainer.io/)**
  * A lightweight management UI dashboard that allows you to easily manage your Docker hosts or Kubernetes clusters.
* **[Lens - The Kubernetes IDE](https://k8slens.dev/)**
  * A powerful desktop IDE that simplifies monitoring, debugging, and managing large-scale Kubernetes clusters in real time.
* **[Dive](https://github.com/wagoodman/dive)**
  * A command-line tool for exploring a Docker image layer by layer, identifying file changes, and discovering ways to shrink your image size.
